# HackFinance_Ingenieros_Ingeniosos
Repositorio en el cual se implementa un sistema que mide la viabilidad de construcción sobre un terreno en función de datos estructurados y no estructurados

Países:
    - EEUU
    - Malasia 
    - India
    - Australia
    - China
    - Reino Unido
    - Japón
    - España

## Estructura

- `ELT/`: obtención de datos y data lake (España, rejilla 3,5 × 3,5 km). Instrucciones en [ELT/README.md](ELT/README.md).
- `pipeline/`: target, variables, modelo y puntuación por celda (lo que pinta la web). Instrucciones en [pipeline/README.md](pipeline/README.md).
